登录 Cookie 设置

方法一（推荐）：从 Application 面板复制

1. 打开 选课系统 并登录成功
2. F12 → 顶部切换到 Application（应用） 标签
3. 左侧展开 Cookies → 点击 bkjx.nenu.edu.cn
4. 任意一个 Cookie 行上右键 → Select All → 再右键 → Copy（复制的是 Name=Value 格式）
5. 全部粘贴到下方输入框

方法二（Edge 网络面板）：从 config 请求头复制

1. 打开 选课系统 并登录成功
2. F12 → 切换到 Network（网络） 标签
3. 按 Ctrl+R 刷新页面，在请求列表中找到 config 这个请求
4. 点击 config → 右侧点 Headers（请求头）
5. 往下翻找到 Request Headers 里的 Cookie: 一行
6. 在 Cookie: 行上右键 → Copy value → 粘贴到下方

※ document.cookie 输出为空是正常的——系统使用了 HttpOnly Cookie，JS 读不到，但 HTTP 请求会自动携带
